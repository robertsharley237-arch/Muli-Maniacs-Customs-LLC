# Multi-Maniacs-Customs-Website-Build

Official website for Multi-Maniacs Customs LLC.

## CJdropshipping product imports

The administrator product page can search CJdropshipping and import
individual products as hidden drafts. Set `CJ_API_KEY` in the backend
environment (see [`backend/.env.example`](./backend/.env.example)). Never
put this API key in frontend configuration or commit its value.

Imported products have no selling price until an administrator edits the
product and sets prices before publishing it.
