How the Custom Project Process Works

Custom projects begin with information gathering so MMC can understand the request before discussing pricing, materials, and scheduling.

1

Submit Your Idea

Share the project type, description, goals, budget, timeline, location, and any available reference images.

2

Project Review

MMC reviews the request and identifies questions, material needs, customization options, and possible project limitations.

3

Scope and Pricing

The project scope, estimated cost, payment requirements, production expectations, and timeline are discussed with the client.

4

Creation and Completion

Once approved, MMC begins the project and communicates with the client about progress, changes, and completion arrangements.

Have an Idea That Is Not Listed?

MMC is built around customization, creativity, and open-minded project development. If a request does not fit one of the service categories above, submit the idea anyway. The project can be reviewed to determine whether it is a good fit for MMC.

Submit a Client Intake Request
Project availability: Services, materials, pricing, timelines, shipping options, and project acceptance depend on the specific request. Submitting an intake request does not guarantee project acceptance or establish a final price.
